# Digirepxyz Documentation

Digirepxyz is a digital repertoire and chord management app for musicians. It stores songs locally, edits and displays ChordPro, transposes chords, provides offline guitar chord diagrams, and supports optional file import, export, AI conversion, sharing, and WebDAV synchronization.

The documentation is split into two paths:

- [User documentation](user/getting-started.md) explains how to use the app.
- [Development documentation](development/getting-started.md) explains how to build, change, and test the project.

The primary supported application target is Android. Other platform code paths are documented where their behavior differs.
